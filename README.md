# SculptAR

## Native iOS app (SwiftUI)

The native app lives in `native-ios/` and offers guided selfie capture or photo library selection. It uses
the [SculptAR website](https://sculptar.app/) icon and has no Flutter dependencies.

1. Open `native-ios/SculptAR.xcodeproj` in Xcode.
2. Select the **SculptAR** scheme and your iPhone to test the camera.
3. Press **Cmd+R**.

For a physical iPhone, select your signing team in **Signing & Capabilities**. On a simulator, use **Choose from Library**.
