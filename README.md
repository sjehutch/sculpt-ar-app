# SculptAR

SculptAR is a native iOS app built with SwiftUI. It offers guided selfie capture,
photo library selection, and on-device lip fullness and definition previews.

1. Open `native-ios/SculptAR.xcodeproj` in Xcode.
2. Select the **SculptAR** scheme and your iPhone.
3. Press **Cmd+R**.

For a physical iPhone, select your signing team in **Signing & Capabilities**.
On a simulator, use **Choose from Library**.
